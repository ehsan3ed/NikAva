موسیقی برای کسانی که نت نمی‌دانند

دو ماژول کوچک از استودیوی صوتی نیک‌آوا که جدا و عمومی منتشر شده‌اند: یکی سوت و زمزمه را به صدای ساز تبدیل می‌کند، دیگری عکس یک صفحهٔ نت چاپی را می‌خواند و می‌نوازد. کد کامل برنامه عمومی نمی‌شود؛ فقط همین لایهٔ «ترجمهٔ موسیقی» باز است تا با هم بهترش کنیم.

🎤 hum2instrument

زمزمه یا سوت بزن، نت‌ها و گام خودکار تشخیص داده می‌شود و با پیانو، گیتار، فلوت، سیم‌ها، بیس یا ای‌پیانو پخش می‌شود. خروجی WAV هم می‌گیری.

humToInstrument(samples, sampleRate, { instrument: "piano" })
دمو را باز کن README

🎼 score2sound

عکس صفحهٔ نت چاپی را بده: خط حامل، نت‌ها و ارتفاع‌شان خوانده می‌شود و همان ملودی با ساز پخش می‌شود. فعلاً تک‌صدایی و برای صفحات تمیز.

imageToNotes(imageData, { clef: "treble", bpm: 96 })

چه چیزی باز است و چه چیزی نه

عمومی (همین ریپو)
  • تشخیص پیچ YIN و تبدیل به نت
  • تشخیص گام و اصلاح نت به داخل گام
  • سینت‌سایزر شش سازه
  • خواندن نت از عکس (خط حامل، نت‌سر، ارتفاع)
خصوصی (اپلیکیشن نیک‌آوا)
  • موتور ضبط، میکس پادکست و تایم‌لاین
  • زنجیرهٔ تیون وکال و افکت‌ها
  • پوستهٔ موبایل و ذخیره‌سازی پروژه

اجرا در ۳۰ ثانیه

git clone <repo> nikava-open-audio
cd nikava-open-audio
npm test        # دو تست خودکار، بدون وابستگی
npm run serve   # سپس /hum2instrument/demo و /score2sound/demo

دنبال همکاری در چه چیزهایی هستیم

  • نت‌خوانی: ساقه و پرچم نت‌ها، دولا و سه‌لا، علامت‌های عرضی کنار نت
  • گام‌های غیرغربی: شور، ماهور، پنتاتونیک برای تشخیص گام
  • سازها: ماریمبا، جعبه‌موسیقی، برنجی با کیفیت بهتر
  • تست: نمونه‌های واقعی ضبط‌شده و عکس‌های واقعی از نت
